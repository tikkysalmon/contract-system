## เสร็จเพิ่ม (2026-09-03 รอบ 17) — แก้บั๊ก dev-server hot-reload ทำให้ตัวอย่างสัญญาว่างเปล่า
- **root cause ที่ user เจอ "แบบฟอร์มสัญญาไม่มีข้อมูลเลย"**: ไม่ใช่บั๊กที่ logic การ render เลย (ตรวจสอบด้วย

  request") แต่ไฟล์ที่มันไป `require()` ต่อ (เช่น `api/_lib/pdf-text-layout.js`, `api/_lib/docx-blocks.js`)

  ต้นเซสชัน) โค้ดเก่าของ `pdf-text-layout.js` (ที่ยังรับ `opts.body` string ไม่รู้จัก `opts.blocks`) เลยค้างอยู่

  request แทนที่จะลบแค่ไฟล์เดียว กัน bug แบบนี้เกิดซ้ำกับไฟล์ `_lib/*.js` อื่นในอนาคตด้วย
- **รีสตาร์ท dev-server แล้ว** (จำเป็นเพราะแก้ dev-server.js เอง — ไฟล์ตัวมันเองไม่ได้ hot-reload ตัวเอง) +
  ยิง request จริงผ่าน HTTP (ไม่ใช่แค่เรียก handler ตรงในสคริปต์) ยืนยันแล้วว่าได้เนื้อหาครบ (6 หน้า, มี text
